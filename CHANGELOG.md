## [1.0.0] - 27 November 2026
### Added
- First release: Loki Checkout add-on for Finland
- Finnish address field labels for shipping and billing (Street Name, Housenumber, Addition, Postal code, Municipality)
- Postal code placeholder (00100) and 5-digit input mask for Finnish addresses
- Finland-specific checkout grid layout with a full-width country field

### Fixed
- Country-specific settings now use the new address-specific and country-specific layout handles
